## 2. Executive Summary

**TLS8001** is positioned as a professional demonstration project for presenting how TLS 8001 / Human Resource Audit findings can be transformed from Excel-based audit records into an interactive executive dashboard.

The project is designed to support:

- management-level communication;
- audit finding analysis;
- certification body comparison;
- site-level follow-up;
- trend and Pareto analysis;
- professional GitHub portfolio presentation;
- teaching of HTML, CSS, JavaScript, jQuery, Chart.js and SheetJS through a realistic dashboard prototype.

This repository contains only source code, documentation, demo structure and teaching materials. It must not contain real confidential audit data.

## 4. Project Storyline for Presentation

```text
TLS 8001 / HRA audit data
        ↓
Excel workbook from audit operation
        ↓
Browser-only data processing
        ↓
Dashboard KPI / charts / table / follow-up list
        ↓
Management insight and audit follow-up decision
```

### Presentation narrative

1. **Problem** — audit results are often kept in Excel and are difficult to communicate at management level.
2. **Solution** — convert structured workbook data into an interactive browser dashboard.
3. **Control** — process data in the browser, reduce data-transfer risk, and avoid uploading files to a server.
4. **Output** — present KPI, trend, classification, CB comparison, site follow-up and detail records.
5. **Next step** — use sanitized/mock data for demo and define governance before production use.

## 5. Scope

### In scope

- TLS 8001 / HRA audit finding dashboard prototype.
- Excel import and column mapping concept.
- KPI, chart, table and follow-up visualization.
- GitHub Pages public demo.
- Developer documentation and teaching materials.
- jQuery 4.0.0 teaching examples.

### Out of scope

- Storage of real audit evidence.
- Uploading confidential files to a public repository.
- Backend database, authentication or production authorization workflow.
- Legal conclusion or certification decision automation.
- Replacement of auditor judgment, CB decision or management approval.

## 7. Data Governance and Confidentiality

This is a public repository. Do not commit:

- real TLS 8001 assessment data;
- employee personal data;
- auditor names or identifiable records;
- evidence documents;
- wage, contract, disciplinary or grievance documents;
- confidential CB reports;
- client or site names unless publicly approved.

Use sanitized, mock or training data only.

---

## 8. Recommended Demo Flow

1. Open the live dashboard.
2. Explain that the file is processed locally inside the browser.
3. Import a sanitized Excel workbook.
4. Show KPI cards.
5. Demonstrate filters by CB, site, year, classification and legal status.
6. Explain charts and Pareto analysis.
7. Open detail records.
8. Export CSV or print to PDF.
9. Close with governance, privacy and future production requirements.

See: [`docs/demo-presentation-guide.md`](docs/demo-presentation-guide.md)
