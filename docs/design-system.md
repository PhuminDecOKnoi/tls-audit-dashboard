# Design System / Mood & Tone

ถอดจาก Sheet `Cover`, `EN_Template` และ `TH_Template` ในไฟล์อ้างอิง

- Primary: `#002333` Deep Navy
- Secondary: `#B4BEC9` Ice Gray
- Accent: `#159A9C` Teal
- Background: `#DEEFE7` Soft Ice
- Surface: `#FFFFFF`
- Critical: `#B42318` พร้อมข้อความ/Badge ไม่ใช้สีอย่างเดียว
- Warning: `#9A6700` พร้อมข้อความ/Badge
- Success: `#116B58`
- Font: Segoe UI, Tahoma, system sans-serif
- Border radius: 8–14 px
- Shadow: soft, low contrast
- Grid: 16 px base spacing
- Visual direction: clean, cool, modern, trustworthy, audit-professional
