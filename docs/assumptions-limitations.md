# Assumptions, Limitations และข้อมูลที่ควรขอเพิ่ม

## Assumptions
- หนึ่งแถวใน NC_Log เท่ากับหนึ่ง Finding
- Remarks ที่มีค่า Closed ใช้เป็นหลักฐาน Closed เท่าที่ไฟล์รองรับ
- วันที่ช่วงใช้วันสิ้นสุดเพื่อจัดลำดับแนวโน้ม โดยเก็บข้อความเดิมไว้แสดงผล

## Limitations
- ไม่มี Pass/Fail, Province, Region, Certificate Expiry, Responsible Person, Open Date, Closure Date, Impact หรือ Urgency
- ไม่คำนวณ Pass Rate, Overdue อย่างเป็นทางการ, Aging, Certificate Timeline, Map หรือ Risk Matrix

## ข้อมูลที่ควรขอเพิ่ม
- Unique NC/CAR Reference
- Province / Region
- Finding Open Date / Closure Date
- Corrective Action Owner
- Workflow Status และ Status Date
- Certificate Issue / Expiry Date
- Impact และ Urgency criteria ที่ได้รับอนุมัติ
